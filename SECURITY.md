# Security reports

Report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/gjl-io/gjl/security/advisories/new).
Include the affected gjl version, operating system, reproducible steps,
and the impact. Clearly state if the issue is actively exploitable or exposes
credentials or private data. Do not publish exploit details, credentials,
request bodies, private keys, or other people's data in a public issue.

Use [GitHub Issues](https://github.com/gjl-io/gjl/issues/new) for non-security
bugs.

Identify the affected and tested gjl versions in the report. Alpha
releases do not promise state-file compatibility with later alphas.
