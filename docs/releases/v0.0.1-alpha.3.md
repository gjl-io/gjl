## gjl v0.0.1-alpha.3

This alpha improves Door setup and development isolation across Windows, Linux, and macOS.

- Adds coding agent HOME registration and Door listener connections for Codex, Claude Code, and OpenCode, with Desktop and CLI management.
- Separates development IPC, state, and Desktop controls from installed production instances.
- Refines the dashboard, listener and Route setup, and Fixed Host management; removes simulated activity.
- Fixes exact checksum matching in the Unix installer and recognition of prerelease versions in daemon status.
