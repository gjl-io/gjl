## gjl v0.0.1-alpha.7

This alpha improves local traffic inspection and record storage management.

- Adds request and response header inspection with authentication values masked before local storage.
- Shows record storage usage and supports reclaiming unused space and moving records to another local drive.
- Adds individual, selected, and filtered record deletion in Desktop and CLI.
- Keeps activity inspection, exports, and deletion scoped to the selected role and Route.
