## gjl v0.0.1-alpha.6

This alpha improves activity inspection, usage reporting, and optional local diagnostics.

- Groups OpenAI WebSocket requests and responses by generation for clearer activity details and usage totals.
- Adds bounded, incremental request and response inspection with raw views and full file saving.
- Expands verified OpenAI model and service-tier pricing and clarifies unavailable usage and pricing.
- Adds optional local diagnostic recording and export in Desktop and CLI, with recording off by default.
- Improves Fixed Host permission handling and isolation between development and installed environments.
