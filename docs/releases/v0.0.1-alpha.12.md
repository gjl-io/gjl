## gjl v0.0.1-alpha.12

This alpha improves Windows Desktop startup, coding-agent management, and installation.

- Improves Desktop startup from an administrator-run Windows daemon while keeping Desktop under the signed-in user's normal permissions.
- Allows coding-agent registration and connection management when the daemon runs with administrator privileges for the same user.
- Resolves the latest official release in installation scripts and reports lookup failures clearly.
