## gjl v0.0.1-alpha.8

This alpha improves record storage and Windows Desktop reliability.

- Combines activity, bodies, and masked headers in one local record store.
- Resets activity and body records from earlier alphas on the first start; usage history is preserved.
- Simplifies record storage information across all eight Desktop languages.
- Keeps one Windows Desktop window and reliably focuses it from the tray or CLI.
