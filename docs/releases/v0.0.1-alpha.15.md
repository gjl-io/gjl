## gjl v0.0.1-alpha.15

- New Door and Gate listeners accept requests up to 64 MiB by default, including larger Codex requests.
- When gjl rejects an oversized HTTP request, the error identifies the listener and its size limit.
- Existing listeners keep their saved settings. To accept larger requests on a listener set to 16 MiB, edit its maximum request body size in Desktop.
