## gjl v0.0.1-alpha.2

First public alpha for Windows, Linux, and macOS.

- Uses `gjl` consistently for the product, executable, CLI, service, Desktop
  application, local state, and public protocol identifiers.
- Keeps Door, Gate, and Vault as the three unprefixed core role names.
- Includes clean-install verification for the owner-only local state and
  operational log directories.
