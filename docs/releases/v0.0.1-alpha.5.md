## gjl v0.0.1-alpha.5

This alpha improves live traffic visibility and response usage reporting.

- Shows recent Listener and Route traffic with separate glows, and Route waves when an LLM response completes.
- Displays each Route's latest response model, reasoning settings, token usage, and API-equivalent price, with recent summaries in the dashboard footer.
- Improves response-level usage accounting, including WebSocket responses, and updates OpenAI model pricing.
- Clarifies unavailable usage, pricing, and response metadata across all eight Desktop languages.
